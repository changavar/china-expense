# China Trip Expenses

A private, offline-first iPhone PWA for tracking trip expenses in CNY and AED.

- All data stays on the device in IndexedDB
- No backend, accounts, analytics, CDNs or external APIs
- Custom categories, direct CNY/AED entry, reports, CSV/PDF/JSON exports
- Installable from Safari via Add to Home Screen

Open the app: https://changavar.github.io/china-expense/

This repository contains only the built static application. Personal expense data is never stored here.
